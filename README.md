#Desafío 9 - Electric Car Store

Este proyecto es un desafío práctico correspondiente al curso de Desarrollo Web Frontend del PEAM (UNSE).

El objetivo del trabajo es maquetar la interfaz de una tienda de vehículos eléctricos con dos versiones de layout (Mobile y Escritorio) aplicando los conocimientos adquiridos en clase.

Para su construcción se utilizaron tecnologías como HTML, CSS y Bootstrap, haciendo especial énfasis en el uso de media queries y breakpoints para lograr un diseño responsivo, combinando CSS Grid (mediante grid-template-areas) para la estructura general del layout y Flexbox para la distribución de elementos dentro de cada sección, como el menú de navegación, la barra de filtros y las tarjetas de producto.
